Rekomendasi Kesehatan

    Tentang Health Predictor

    Platform ini menggunakan algoritma K-Nearest Neighbors (KNN) yang telah dilatih dengan dataset klinis untuk memberikan prediksi akurat.

    Deteksi Stunting

    Menggunakan model KNN berbasis data usia, tinggi, berat, dan jenis kelamin balita (0–59 bulan) untuk mendeteksi risiko stunting.

    Prediksi Diabetes

    Model KNN dilatih pada dataset Pima Indians Diabetes menggunakan 8 parameter klinis untuk mengklasifikasikan risiko diabetes.

    Laporan PDF

    Unduh hasil prediksi lengkap dengan data input, interpretasi, dan rekomendasi kesehatan dalam format PDF profesional.
